# Черновик искового заявления

## Триггеры

«напиши иск», «нужен иск по делу», «составь исковое», «черновик иска»,
«иск на [сторону]». НЕ триггер: возражение/отзыв/жалоба (→ draft-objection).

## Фаза 0 — фактура (quality gate: без неё дальше нельзя)

Проверь, что есть:
- Суд (какой, адрес)
- Истец и Ответчик — полные реквизиты (ОГРН/ИНН/адрес для юрлица;
  ФИО/паспорт/адрес для физлица — ТОЛЬКО если Денис их передал, не спрашивай
  больше, чем нужно для документа)
- Предмет спора и сумма требований
- Факты дела — своими словами Дениса или документами
- Нормы права — если Денис дал текст нормы или прямо назвал статью, бери
  её. Если нет — не выдумывай, помечай `[ПРОВЕРЬ НОРМУ САМ]`

Чего-то не хватает → спроси прямо, одним сообщением, что именно нужно.
Не начинай писать «на всякий случай».

## Фаза 1 — выбор режима (из style.md)

- **Плотный/фактологический** — для сложных B2B-споров с множеством
  однотипных эпизодов (партии, накладные, платежи): сплошной поток
  факт → норма → «Таким образом, вывод», минимум подзаголовков.
- **Секционный** — для более простых/частных дел: явные подзаголовки
  («Фактические обстоятельства дела.», расчётная таблица при неустойке).

Выбирай по сложности дела, не по умолчанию один и тот же режим всегда.

## Фаза 2 — сборка по скелету

Следуй скелету иска из `knowledge/methodology.md` дословно по порядку:
шапка → заголовок → тело (факты + нормы, каждая норма развёрнуто
процитирована перед применением, «Таким образом» после каждого блока) →
опционально список практики единым абзацем → «На основании изложенного,
руководствуясь ст.ст. …» → «ПРОШУ СУД:» с пронумерованными требованиями →
«ПРИЛОЖЕНИЯ:» подробным постраничным списком → подпись представителя.

## Фаза 3 — self-check (обязателен, из methodology.md)

Прогони вслух 5 пунктов чек-листа перед выдачей. Любой пункт не пройден →
не отдавай, исправь или помечай.

## Фаза 4 — выдача

Два отдельных блока в ответе:
1. Текст черновика (готов к копированию в документ)
2. «Проверь это:» — список того, что не проверено самим Солоном (нормы
   без подтверждённого текста, цифры, ссылки на практику)

**Exit criteria:** оба блока отданы, self-check пройден, ни одного факта
или нормы вне переданных материалов.

## Error recovery

- Денис прислал противоречивые факты (например, две разные суммы) →
  не выбирай сам, спроси какая верна
- Норма нужна, но текста нет → `[ПРОВЕРЬ НОРМУ САМ: предполагаю ст. Х,
  не проверено]`, не блокирует весь черновик, но обязательно в «Проверь это»

## Пример 1 (упрощённый, вымышленные данные — не реальное дело Дениса)

**Input:** «Нужен иск. Истец — ООО "Вектор", ответчик — ООО "Атлас-Логистик".
Ответчик не оплатил услуги хранения по договору №12 от 01.03.2025, долг
340 000 руб. Акт МХ-1 подписан обеими сторонами, претензию направляли,
ответа нет. Дело в Арбитражный суд Московской области.»

**Output:**
```
В Арбитражный суд Московской области
Истец: ООО «Вектор» [реквизиты — ЗАПРОШЕНЫ у Дениса, если не даны]
Ответчик: ООО «Атлас-Логистик» [реквизиты]
Цена иска: 340 000 руб.

ИСКОВОЕ ЗАЯВЛЕНИЕ
о взыскании задолженности по договору хранения

Между Истцом и Ответчиком заключен Договор № 12 от 01.03.2025 (далее —
Договор), в соответствии с которым Истец принял на себя обязательства по
хранению имущества Ответчика.
Факт оказания услуг подтверждается актом приема-передачи по форме МХ-1,
подписанным обеими сторонами.
Согласно п. 1 ст. 886 Гражданского кодекса Российской Федерации (далее —
ГК РФ) [ПРОВЕРЬ НОРМУ САМ: точный текст п.1 ст.886 не был передан, привожу
по общей памяти — сверь перед подачей] по договору хранения одна сторона
(хранитель) обязуется хранить вещь, переданную ей другой стороной
(поклажедателем).
[... норма об оплате услуг хранения, развёрнуто ...]
Таким образом, обязанность Ответчика по оплате оказанных услуг является
установленной и не исполненной.
Истцом соблюден претензионный порядок разрешения спора — в адрес Ответчика
направлена претензия, которая оставлена без удовлетворения.
На основании изложенного, руководствуясь ст. 886 ГК РФ, ст.ст. 125, 126 АПК РФ,

ПРОШУ СУД:
1. Взыскать с ООО «Атлас-Логистик» в пользу ООО «Вектор» задолженность в
   размере 340 000 руб.
2. Взыскать расходы по уплате государственной пошлины.

ПРИЛОЖЕНИЯ:
1. Копия Договора № 12 от 01.03.2025 — [N] л.
2. Копия акта МХ-1 — [N] л.
3. Копия претензии с подтверждением направления — [N] л.
4. Копия платежного поручения об оплате госпошлины — 1 л.

Представитель Истца
по доверенности                                        [ФИО]
```
Проверь это:
- Реквизиты сторон (ОГРН/ИНН/адреса) — не подтверждены, подставлены как
  плейсхолдер
- п. 1 ст. 886 ГК РФ — текст нормы не был передан, процитирован по общей
  памяти, сверить перед подачей
- Число листов в приложениях — не указано, проставить по факту

## Пример 2 (edge case — фактуры не хватает)

**Input:** «Напиши иск на Иванова, он должен 200 тысяч.»

**Output:** «Данных для черновика мало — нужны минимум: полное наименование/
ФИО Ответчика с реквизитами, основание долга (договор/накладная/расписка),
суд, куда подаём, и есть ли направленная претензия. Пришли — соберу.»
(Не начинать писать текст на предположениях.)
