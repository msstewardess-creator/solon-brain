# Черновик возражения / отзыва / жалобы

## Триггеры

«напиши возражение на отзыв», «нужен отзыв на иск», «составь апелляционную
жалобу», «разбери доводы ответчика/истца». НЕ триггер: первичный иск
(→ draft-claim).

## Фаза 0 — фактура (quality gate: без неё дальше нельзя)

Обязательно нужен:
- Текст (или как минимум точный пересказ) документа оппонента — отзыва,
  апелляционной жалобы, ходатайства — на который отвечаем. Без него
  опровергать нечего, не собирай возражение «в общем».
- Дело: номер, суд, судья, стороны, суть требований
- Позиция Дениса — с чем конкретно не согласен, какие есть контрдоказательства

Не хватает документа оппонента → спроси прямо, не собирай возражение
из головы.

## Фаза 1 — рекапитуляция

1-2 фразы: «В производстве [суд] находится дело №[N] по иску [Истец] к
[Ответчик] о [предмет]. [Сторона] не согласен(на) с изложенными доводами
[Оппонента] в связи со следующим:»

## Фаза 2 — поблочное опровержение (сигнатурный паттерн Дениса)

Для каждого довода оппонента — отдельный блок, по возможности зеркалящий
нумерацию документа оппонента (если он нумеровал свои пункты):

```
Довод [Оппонента] о том, что [пересказ довода] считаем несостоятельным
в связи с тем, что [суть разбора].
[Норма — развёрнуто процитирована, не просто номер] → Таким образом, [вывод].
```

Не пропускай ни один существенный довод оппонента молча — либо
опровергаешь, либо явно помечаешь, что довод не оспаривается.

## Фаза 3 — опционально: практика + резолютивная часть

Если есть релевантная практика — список одним абзацем (не разбор каждого
дела по отдельности, это не голос Дениса). Затем: «На основании
изложенного, руководствуясь ст.ст. …» → «ПРОШУ СУД:» / «ПРОСИТ:» /
«ПРОШУ АРБИТРАЖНЫЙ СУД [город]:» — в зависимости от типа документа (см.
`knowledge/style.md`, там же — когда какой вариант употреблялся).

## Фаза 4 — self-check + выдача

Тот же чек-лист и тот же формат «текст + Проверь это», что в `draft-claim`.
Дополнительно проверь: каждый довод оппонента либо опровергнут, либо явно
оставлен без возражений (не потерян случайно).

**Exit criteria:** ни один довод оппонента не пропущен молча, self-check
пройден, оба блока (текст + проверь это) отданы.

## Error recovery

- Оппонент привёл довод, на который у Дениса нет контраргумента → не
  выдумывай опровержение, честно скажи «довод [Х] сходу нечем перебить,
  нужна твоя позиция» — не притворяйся, что аргумент найден
- Практика оппонента выглядит нерелевантной делу → скажи это прямо (как
  в реальных документах Дениса — «представленная практика не является
  аналогичной настоящему спору»), не игнорируй молча

## Пример (упрощённый, вымышленные данные)

**Input:** «Вот отзыв Ответчика [текст: "Ответчик утверждает, что просрочка
акта возникла по вине самого Истца, который поздно предоставил документы"].
Это неправда — мы предоставили документы в срок по переписке от 03.04.»

**Output:**
```
В производстве Арбитражного суда [Х] находится дело №[N] по иску ООО
«Вектор» к ООО «Атлас-Логистик» о взыскании задолженности.
Истец не согласен с изложенными доводами Ответчика в связи со следующим:

Довод Ответчика о том, что просрочка подписания акта возникла по вине
Истца, который поздно предоставил документы, считаем несостоятельным в
связи с тем, что документы были направлены Истцом 03.04.2025, что
подтверждается перепиской сторон (Приложение № [N]).
Согласно ст. 65 АПК РФ [развёрнутая цитата] каждое лицо должно доказать
обстоятельства, на которые оно ссылается как на основание своих
требований и возражений. Ответчиком доказательств несвоевременного
предоставления документов Истцом не представлено.
Таким образом, довод Ответчика не подтверждён материалами дела и подлежит
отклонению.

На основании изложенного, руководствуясь ст. 65 АПК РФ,

ПРОШУ СУД:
Удовлетворить исковые требования ООО «Вектор» в полном объеме.

ПРИЛОЖЕНИЕ:
1. Копия переписки от 03.04.2025 — [N] л.

Представитель Истца
по доверенности                                        [ФИО]
```
Проверь это:
- Номер дела, суд, точные даты переписки — подставлены по тому, что дал
  Денис, сверить перед подачей
- Число листов приложения — не указано
