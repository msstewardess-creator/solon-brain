# Глоссарий вагонных споров (добавлено 2026-08-11)

Основная часть практики Дениса — споры о грузовых вагонах (аренда, ремонт,
подготовка/промывка-пропарка, взыскание задолженности между операторами
подвижного состава). Это не общий юридический справочник — только термины,
которые реально несут юридический вес в этой конкретной нише, чтобы Солон
не изобретал их заново в каждом деле.

## Проверенные источники (читать отсюда, не по памяти)

- **Устав железнодорожного транспорта РФ** (ФЗ №18-ФЗ от 10.01.2003) —
  полный текст читается на `legalacts.ru/doc/federalnyi-zakon-ot-10012003-n-18-fz-ustav/`
  (проверено — реальная цитата ст.1, ст.2). На `consultant.ru` и
  `base.garant.ru` та же статья закрыта платной стеной — не пытаться там.
- **Классификатор "Основные неисправности грузовых вагонов" (КЖА 2005 04/05)**
  — не один официальный файл, а отраслевой стандарт, разошедшийся по
  зеркалам. Рабочее зеркало с реальной таблицей кодов —
  `gdzp.ru/poleznaya-informaciya/kuzova-gruzovyh-vagonov/vyborka-iz-klassifikatora-kzha-200504-osnovnye-neispravnosti-/`
  (проверено — коды вида «101 — Сход с рельсов», «150 — Грение буксы»
  реально читаются). Тот же классификатор встречается как приложение внутри
  распоряжений РЖД на `sudact.ru` и `base.garant.ru/70997042/` — если нужен
  контекст конкретного распоряжения, а не просто таблица кодов.
- **Правила перевозок грузов ЖД транспортом** — россыпь отдельных приказов
  Минтранса, единого стабильного адреса нет. Искать каждый документ отдельно
  на `legalacts.ru` по номеру приказа, не полагаться на угаданный URL.

## Специализированные источники — только для человека, не для Солона

Не читаются автоматически (нет рабочего доступа для чтения инструментом),
но существуют и стоит подсказать Денису при случае:
- `rollingstockworld.ru` — отраслевое издание, есть разбор практики по
  спорам о ремонте вагонов
- `slp-legal.ru`, `suvorov.legal` — юридические блоги по теме простоя
  вагонов и аренды подвижного состава

## Термины и их юридический вес

| Термин | Значение |
|---|---|
| **Простой вагона** | Время сверхнормативного нахождения вагона у контрагента — основа расчёта неустойки. Завязано на ст. 39, 62, 100 Устава. |
| **Текущий отцепочный ремонт (ТОР)** | Внеплановый ремонт с отцепкой вагона — ключевой момент в спорах "кто платит" между оператором, депо и РЖД. |
| **Промывка-пропарка** | Очистка цистерн паром — отдельный вид услуги, часто спорится вместе с ремонтом, но по отдельному основанию. |
| **Оператор подвижного состава** | Статус, отдельный от перевозчика/собственника — от него зависит, есть ли у стороны право на иск. |
| **Грузоотправитель / грузополучатель** | Определены в ст. 2 Устава — от этого зависит, связаны ли стороны договором вообще. |
| **Накопительный (учётный) вагонный лист / накладная** | Основной доказательный документ по перевозке — то, на что ссылается расчёт требований. |
| **Забраковка вагона / акт браковки** | Документ, фиксирующий неисправность — с него начинается обязанность ремонта. |
| **Гарантийный срок на ремонт** | Спорится между депо и оператором, если неисправность повторилась. |
| **Рекламационно-претензионная работа** | Формальный порядок предъявления претензий по качеству ремонта. |
| **Код неисправности (по КЖА)** | Ссылка на конкретный пункт классификатора — доказательная опора в спорах о качестве ремонта. |
| **Собственник вагона (арендодатель) / арендатор** | Роли сторон в договоре аренды подвижного состава. |
| **Простойные сутки / сталийное время** | Единица расчёта штрафа за простой. |
| **Инфраструктура ЖД транспорта общего пользования** | Термин Устава, определяющий границу ответственности РЖД. |
| **Уведомление о готовности вагона** | Момент, запускающий/останавливающий отсчёт простоя. |
| **Акт общей формы (ГУ-23)** | Стандартный документ фиксации происшествия — часто фигурирует как приложение. |

## Правило использования

Термин из этой таблицы — не готовая формулировка для черновика, а подсказка
"о чём вообще идёт речь" и куда смотреть. Конкретную норму или цитату
всё равно брать из проверенного источника (см. выше), не додумывать
формулировку по одному только упоминанию в этом файле.
